Hamza Builds site (plain HTML, CSS, JS. No build step.)

Upload these files to the root of the GitHub repo. Vercel serves them as they are.

To add your photo: save it as img/portrait.png (a cut-out with a transparent background looks best).
Until it is there, the logo is shown in the middle of the hero.

To change a project card, replace the image files in img/ (naibi-*, aby-*, olive-*) or edit the card in index.html.

Reviews: run db/1-reviews-table.sql, then 2, then 3 in the Supabase SQL editor.
Owner page: /admin.html
All projects page: /projects.html (edit the list in that file; add a link by turning the "Link coming soon" text into a Visit site button).
